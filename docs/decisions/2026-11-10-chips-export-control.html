01SCOPE问题与边界

真正要选的是什么：在 2026-11-10 至 2027-02-08 这 90 天内，是否为「半导体出口管制升级」提前调整供应链与合同条款，以及调整到什么程度（不动 / 轻度对冲 / 激进重构）。决策者假定为一家在半导体供应链中有采购或敞口的企业；若角色不同（如投资机构、政策部门），第 4–6 节需重估。

不包含：超过 90 天的产能布局、对华直接投资、具体交易时点、中国国内政策本身的走向。

最晚决策时间：安全库存与替代供应商认证通常需要 45–90 天前置期（估计）。因此实质性决策最迟应在 2026-12-15 前作出，否则缓冲无法在 2027-02-08 前到位；纯监测姿态可推迟至 2027-01-15。

03UNCERTAINTY关键不确定性

变量 1：美国管制的适用范围

  • 当前区间：定向（个别企业/特定终端）约 50–70% vs 系统性（全链条多点）约 30–50%（估计）。
  • 判断依据：[25] 显示政策压力存在；[13][35] 显示 Nvidia 处于政治风暴中心，但材料中没有任何官方规则文本。
  • 为什么重要：定向情形只需局部应对；系统性情形需要全面供应链重构，成本相差数倍。

变量 2：中国反制的强度与形式

  • 当前区间：从「口头警告 + 少量清单」到「镓/锗/稀土出口许可 + 不可靠实体清单扩容」之间的任一位置（估计）。

  • 为什么重要：反制会改变成本结构与合规风险，且可能先于美国新政落地。

变量 3：日本等第三方经济体的对齐程度

  • 当前区间：从「完全追随」到「保持独立供应链」之间（估计）。
  • 判断依据：[24] 显示日本在重组芯片材料供应链；[29] 显示日本供应商同时服务于非美项目。
  • 为什么重要：若日本不追随，管制有效性下降，同时出现可替代供给——直接改变选项 2 的可行性。

变量 4：供给紧张是否会自我缓解

05OPTIONS选项评估

选项 1：不做决定（仅监测）

  • 预期收益：避免过早投入的浪费（估计可节省库存占用与认证费用，规模取决于采购额，材料不足无法量化）。
  • 最坏情况：情景 B 下关键芯片断供，交付违约并流失客户。
  • 可逆性：高——可随时启动其他选项。
  • 执行成本：低——仅需现有人力持续阅读联邦公报与行业通报。
  • 致命缺陷：响应滞后。安全库存与供应商认证需 45–90 天前置期（估计），触发后再行动可能来不及。

选项 2：分层对冲（核心推荐）

  • 预期收益：情景 A 下保住大部分交付（估计 80%+）；情景 B 下争取 1–2 个季度的缓冲窗口。
  • 最坏情况：情景 C + 价格回落 → 库存减值与资金占用；估计减值幅度有限（[10] 显示内存类价格本就面临下行压力）。
  • 可逆性：中高——库存在 6–12 个月内可消化；认证投入部分沉没。
  • 执行成本：中——估计为关键品类 30–45 天安全库存 + 1–2 家替代供应商认证费用。

选项 3：制度性对冲

  • 预期收益：除选项 2 外，降低法律与关系风险，情景 B 下保护合同与客户。
  • 最坏情况：游说无果、客户拒绝重谈条款，投入沉没。
  • 可逆性：中——合同条款变更难以撤回。
  • 执行成本：中高——律师、顾问与行业联盟费用。

选项 4：激进重构

  • 预期收益：情景 B 下生存能力最强。
  • 最坏情况：成本上升 20–40%（估计）、质量认证失败、触发美方审查升级。
  • 可逆性：低——产线切换后难以快速回退。
  • 执行成本：高。

07FALSIFICATION反面证据与证伪条件

出现以下任一情况，本备忘录的核心结论应被推翻或大幅修正：

  1. 90 天内无任何新联邦公报规则，且 Nvidia 案未导致任何出口许可变化 → 则「升级概率约 65%」属高估，应下调至 40% 以下。

  3. 中美在 COP31 或东盟峰会期间达成技术贸易谅解 → 情景 C 概率应上调至 50% 以上，选项 2 的库存目标应下调。
  4. 日本明确拒绝协调并继续扩大对华芯片材料出口 → 情景 B 的「系统性升级有效性」假设被推翻，同时选项 2 的替代供给来源反而扩大。
  5. 马来西亚与台湾关系修复 → [12] 所示的供应链多元化障碍消除，选项 4 的紧迫性下降。
